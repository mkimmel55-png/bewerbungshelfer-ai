# Contributing

Beiträge zu Bewerbungshelfer AI sind willkommen.

## Möglichkeiten mitzumachen

Du kannst zum Projekt beitragen durch:

- Fehlerberichte
- Verbesserungsvorschläge
- neue Funktionen
- bessere Dokumentation
- Übersetzungen
- Pull Requests

## Grundregeln

Bitte beachte:

- Keine erfundenen Qualifikationen in Beispielbewerbungen verwenden.
- Keine echten personenbezogenen Daten öffentlich hochladen.
- Änderungen möglichst klein und nachvollziehbar halten.
- Neue Funktionen kurz dokumentieren.
- Fehler möglichst mit einem Beispiel beschreiben.
